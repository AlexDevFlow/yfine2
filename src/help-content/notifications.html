Notifications

Yfine raises notifications when it has something to tell you: a recurring item is due, a balance is not enough to cover a scheduled payment, a background task finished. This page is the full archive. Recent unread items also appear under the bell icon in the top bar.

What you see
  • A list of notifications. Each has an icon colored by type: alert, warning, info.
  • Each notification has a title, a body, and a timestamp in relative form ("5 minutes ago", "yesterday").
  • Unread items have a highlighted background and bolder title.
  • Tabs at the top filter by type: All, Unread, Alert, Info, Warning.
  • Pagination appears at the bottom when there are more than 20 results in the filter.
Main actions
Mark all as read Clear the unread badge by marking every current notification as read.
Delete all read Clean up the archive. Only already-read items are removed.
Per-notification actions
Mark as read Appears on unread notifications. Removes the highlight but keeps the item in the archive.
Delete Remove one notification.
What triggers a notification
  • Recurring due soon: when a recurring item's due date is within the configured alert window.
  • Insufficient funds: when a scheduled recurring payment would leave the source below zero, and you enabled the insufficient-funds warning on that item.
  • Recurring applied automatically: confirmation that Yfine created a movement for a recurring item set to Automatic.
  • Background task results: import completed, export ready, plugin scanned, and similar events.
The bell icon

The bell in the top bar shows a red counter when you have unread notifications. Clicking it opens a dropdown with the five most recent unread items and a shortcut to this page. Each item in the dropdown has its own dismiss and "mark as read" actions.

Unread notifications also appear as toast pop-ups as they arrive. The toast has a "Mark as read" link if you want to dismiss it right then.
