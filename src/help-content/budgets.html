Budgets

A budget is a spending cap (or income target) tied to a tag and a currency that renews itself every period. Yfine computes how much you've spent live, from the movements carrying that tag, so you always know how much is left.

What you see
  • At the top, period navigation arrows: ‹ previous · current · next ›. Navigation steps each budget in its own cadence (a weekly one by a week, a yearly one by a year).
  • A per-currency rollup: spent / budgeted and what's left, grouped by currency so mixed-currency budgets stay legible.
  • A grid of cards, one per budget, sorted most-at-risk first (over-budget first, then close to the threshold).
  • Each card shows: tag and colour, currency, spent / available, a progress bar, the percentage, how much is left (or how far over you are), the period with its date range, and — when on — the rollover.
  • Pace hints: how much you can spend per day for the days remaining, and a projection for the end of the period if you keep the current pace.
Actions
New Budget Pick a tag, amount, currency, period and type (spending cap or income target).
View movements Opens the movements list already filtered to the budget's tag, so you can see what makes it up.
Edit Change amount, period, threshold or rollover. Changing the rule resets the alert band it last fired on.
Delete Removes the budget. Your movements are untouched.
How it works

A budget materialises nothing per period: the spent figure is recomputed live from movements, so the numbers self-heal when you edit a past movement. A movement counts when it:

  • carries the budget's tag;
  • matches the direction (out for a spending cap, in for an income target);
  • falls in the current period;
  • has a source in the budget's currency.

Transfers and movements excluded from stats never count. External movements (no source, hence no currency) don't count either.

One budget per tag and currency

There can be only one active budget per tag-and-currency pair — it keeps the model simple. If you need the same tag in two currencies (say "Groceries" in EUR and in USD), create two budgets.

Period
  • Weekly: Monday to Sunday.
  • Monthly: first to last day of the month.
  • Quarterly: calendar-aligned three-month blocks (Jan–Mar, Apr–Jun, …).
  • Yearly: the calendar year.

Periods are calendar-aligned and renew on their own — you never recreate them.

Rollover

With rollover on, a period's surplus or overspend carries into the next (envelope-style). Budget 400 and spend 300, and next period you have 500 available; overspend by 100, and next period starts at 300. Without rollover, every period starts clean at the base amount.

Alert threshold

The alert threshold (a percentage) fires a notification when spending reaches it, and another one past 100%. Yfine fires once per band per period, so it never floods you. Set the threshold to 0 to turn that budget's alerts off.

Pace and projection

Yfine compares how far you are through the period with how much you've already spent. It shows how much you can spend per day for the remaining days and a projection for the end of the period: if the projection exceeds what's available, the number turns red as an early warning.

Step by step: create a spending budget
  1. Make sure you have at least one tag (budgets build on tags).
  2. Click New Budget.
  3. Pick the tag (e.g. "Groceries") and the currency.
  4. Enter the limit per period and choose Monthly.
  5. Leave the type on Spending cap.
  6. Optional: set the alert threshold (defaults to 80%) and turn on rollover.
  7. Save. The card appears with the current period's spend already computed.
For a movement to count toward a budget it must carry its tag and sit on a source of the same currency. If a budget looks stuck at zero, check that the movements have the right tag and aren't excluded from stats.
