Recurrentes

Los elementos recurrentes son pagos o ingresos que se repiten con una frecuencia: nómina, alquiler, suscripciones, facturas. Los configuras una vez y Yfine sigue la pista de cuándo toca pagarlos.

Qué ves
  • Arriba, tres mosaicos de resumen mensual por moneda: Salida Mensual, Entrada Mensual y Neto · Mensual. Los totales normalizan los elementos diarios/semanales/anuales a su equivalente mensual.
  • Debajo de los mosaicos, pestañas Todos / Salidas / Entradas para la dirección, un selector de Frecuencia y la indicación "Ordenado por próxima ocurrencia".
  • Una cuadrícula de tarjetas, una por cada elemento recurrente. Cada tarjeta tiene una franja superior de color: verde para ingresos, rojo para gastos.
  • Cada tarjeta muestra el nombre, el importe en su moneda, la frecuencia, el modo de aplicación y la fuente.
  • Una próxima fecha con un distintivo de color: rojo si vence hoy, amarillo si vence dentro de tres días, gris en otro caso.
  • Una línea de información: "vencido", "hoy", "mañana" o "en N días".
  • Botones de acción por tarjeta: Aplicar Ahora, Editar, Eliminar.
Acciones principales
Nuevo Recurrente Crea un elemento recurrente. Rellena nombre, importe, frecuencia, fecha de inicio.
Acciones por tarjeta
Aplicar Ahora Abre un diálogo para confirmar el importe y crear un movimiento real para este ciclo.
Editar Cambia cualquier campo. Afecta a los ciclos futuros.
Eliminar Borra el elemento recurrente. Los movimientos pasados que creó se conservan.
Cómo funcionan los recurrentes

Un elemento recurrente es una plantilla, no un movimiento. Describe cuándo y cuánto. Cada vez que toca, Yfine crea un movimiento automáticamente o te pide confirmación, según su modo de aplicación.

Frecuencia
  • Diaria: se repite todos los días.
  • Semanal: cada siete días, contando desde la fecha de inicio.
  • Mensual: el mismo día cada mes. Si ese día no existe en un mes más corto (el 31 en febrero), se usa el último día del mes.
  • Anual: misma fecha cada año.
Modo de aplicación
  • Automático: cuando pasa la fecha de vencimiento, Yfine crea el movimiento por su cuenta.
  • Confirmación manual: Yfine te avisa cuando toca. Revisas el importe, lo ajustas si hace falta y pulsas Aplicar Ahora para crear el movimiento.

Usa confirmación manual para elementos cuyo importe varía (facturas de luz, suscripciones variables). Usa automático para los fijos (alquiler, suscripciones con precio cerrado, nómina).

Avisos

En el formulario puedes configurar:

  • Avisar N días antes: con cuántos días de antelación quieres el recordatorio. Aparece una notificación y queda bajo el icono de la campana.
  • Avisar si no hay fondos suficientes: si está marcado, Yfine compara el importe con el saldo actual de la fuente y avisa si el saldo no llega.
Filtros
  • Pestañas de dirección (Todos / Salidas / Entradas): muestra todo, solo gastos o solo ingresos.
  • Frecuencia: menú desplegable para acotar a diaria, semanal, mensual o anual. Se combina con las pestañas.
Paso a paso: configurar una suscripción
  1. Pulsa Nuevo Recurrente.
  2. Introduce el nombre (por ejemplo, "Netflix").
  3. Introduce el importe y elige la moneda.
  4. Elige Gasto.
  5. Elige Mensual como frecuencia.
  6. Pon la fecha de inicio en la próxima fecha de cobro. Deja fecha de fin vacía.
  7. Elige la fuente de la que sale el pago.
  8. Elige Automático si el importe no cambia nunca.
  9. Guarda. La tarjeta aparece aquí y en el panel bajo "Próximos".
Paso a paso: aplicar manualmente un elemento vencido
  1. Encuentra la tarjeta con el distintivo rojo o amarillo.
  2. Pulsa Aplicar Ahora.
  3. Confirma el importe en el diálogo. Ajústalo si la factura es diferente este mes.
  4. Opcional: añade una nota.
  5. Confirma. Se crea un movimiento, el saldo de la fuente se actualiza y la próxima fecha avanza.
Si te saltas aplicar un recurrente durante varios ciclos, Aplicar Ahora te pregunta si quieres recuperar todos los ciclos perdidos o solo el más reciente.
