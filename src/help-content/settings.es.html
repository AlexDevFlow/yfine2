Configuración

Todas las preferencias de Yfine viven aquí, divididas en pestañas. La barra lateral izquierda es el navegador de pestañas en escritorio, y una fila desplazable en móvil.

Resumen de pestañas
Tema Claro, oscuro o sistema (sigue el sistema operativo). También el estilo de navegación en móvil.
Idioma Idioma de la interfaz, formato de fecha y moneda base para los totales.
Carteras Activa o desactiva la obtención de precios en vivo.
Red Habilita el acceso desde la red local para abrir Yfine desde otros dispositivos de casa. Cambia el puerto del servidor.
Seguridad Pon o cambia la contraseña que cifra la base de datos.
Datos Exporta los datos, importa una copia, descarga o limpia los registros, borra todos los datos.
Importaciones Importa movimientos de extractos bancarios y otras apps de finanzas. Preajustes para formatos comunes.
Plugins Sube plugins personalizados. Un informe de análisis marca lo que parezca no seguro.
Tema

Tres botones arriba: Claro, Oscuro, Sistema. "Sistema" sigue los ajustes del sistema operativo y cambia cuando cambia el sistema.

Debajo: el estilo de navegación móvil. Elige "Barra lateral" para mantener el menú a la izquierda en móviles, o "Inferior" para una barra inferior al estilo de las apps nativas.

Idioma
  • Idioma: español, inglés, italiano, ucraniano. La interfaz se recarga en el nuevo idioma al guardar.
  • Formato de fecha: dd/mm/aaaa, mm/dd/aaaa o aaaa-mm-dd. Afecta a cada fecha mostrada en la app.
  • Moneda base: la predeterminada usada al crear una fuente o un ahorro sin moneda seleccionada.
Red

Yfine solo escucha en localhost por defecto. Activar el acceso de red local lo hace accesible desde otros dispositivos de tu red doméstica (útil para abrir la app en el móvil mientras el ordenador está encendido). Yfine muestra la URL a escribir en el otro dispositivo.

El puerto del servidor se puede cambiar si el predeterminado ya está ocupado. Aparece un aviso "reinicio necesario" tras guardar.

Seguridad

Poner una contraseña activa el cifrado AES-256-GCM del archivo de base de datos. La clave se deriva de la contraseña y nunca se almacena.

  • Con contraseña: la app la pide al arrancar. La base de datos se descifra en memoria y se recifra al cerrar.
  • Sin contraseña: la base de datos es un archivo SQLite normal.
Datos: exportar, importar, restablecer
  • Exportar: descarga una copia JSON (solo datos principales) o un archivo completo .yfine (datos + plugins + configuración).
  • Exportar Excel / PDF: formatos para imprimir o compartir.
  • Importar: elige un archivo exportado. Una ventana de vista previa muestra qué se importará antes de confirmar.
  • Registros: descarga o limpia el registro de la aplicación.
  • Borrar todos los datos: vacía todas las fuentes, movimientos, carteras, etiquetas, recurrentes, ahorros, caprichos y notificaciones. No toca la configuración.
Pestaña Importaciones

La pestaña Importaciones es un asistente paso a paso. Elige la fuente destino, elige un preajuste de formato (por ejemplo, "CSV extracto bancario"), sube el archivo, mapea columnas si hace falta y revisa la lista de movimientos que se crearán. La detección de duplicados corre durante el paso de revisión.

Plugins

Los plugins extienden Yfine con nuevas páginas, entradas de menú o lógica. Para instalar uno:

  1. Pulsa el botón de subida y elige el archivo del plugin.
  2. Yfine ejecuta un análisis estático del código. Los hallazgos críticos bloquean la instalación. Los avisos permiten continuar bajo tu criterio.
  3. Tras el análisis, confirma para instalar.
  4. Reinicia la app. La entrada del plugin aparece en la barra lateral.
Exporta tus datos antes de cualquier "Borrar todos los datos" o instalación arriesgada de plugin. El archivo .yfine contiene todo lo necesario para devolver la app al estado actual.
Los plugins corren con los mismos permisos que Yfine. El analizador marca los problemas evidentes, pero no puede detectarlo todo. Instala solo plugins de fuentes que consideres fiables.
