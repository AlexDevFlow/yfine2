Impostazioni

Tutte le preferenze di Yfine sono qui, divise in schede. La barra laterale sinistra è il navigatore delle schede su desktop, e una riga scorrevole su mobile.

Panoramica delle schede
Tema Chiaro, scuro o automatico (segue il sistema operativo). Inoltre lo stile di navigazione su mobile.
Lingua Lingua dell'interfaccia, formato data e valuta base per i totali.
Portafogli Attiva o disattiva il recupero dei prezzi live.
Rete Abilita l'accesso dalla rete locale per aprire Yfine da altri dispositivi di casa. Cambia la porta del server.
Sicurezza Imposta o cambia la password che cifra il database.
Dati Esporta i dati, importa un backup, scarica o svuota i log, ripristina tutti i dati.
Importazioni Importa movimenti da estratti conto bancari e altre app di finanza. Preset per i formati più comuni.
Plugin Carica plugin personalizzati. Un report di scansione segnala codice potenzialmente non sicuro.
Tema

Tre pulsanti in alto: Chiaro, Scuro, Automatico. "Automatico" segue le impostazioni del sistema operativo e cambia quando cambia il sistema.

Sotto: lo stile di navigazione mobile. Scegli "Barra laterale" per mantenere il menu a sinistra sui telefoni, oppure "In basso" per una barra inferiore simile alle app native.

Lingua
  • Lingua: italiano, inglese, spagnolo, ucraino. Al salvataggio l'interfaccia si ricarica nella nuova lingua.
  • Formato data: gg/mm/aaaa, mm/gg/aaaa o aaaa-mm-gg. Influisce su ogni data mostrata nell'app.
  • Valuta base: quella predefinita usata creando una fonte o un risparmio senza valuta selezionata.
Rete

Yfine ascolta solo su localhost di default. Attivando l'accesso rete locale diventa raggiungibile da altri dispositivi della tua rete di casa (utile per aprire l'app sul telefono mentre il computer è acceso). Yfine mostra l'URL da digitare sull'altro dispositivo.

La porta del server può essere cambiata se quella predefinita è già occupata. Dopo il salvataggio compare un avviso "richiesto riavvio".

Sicurezza

Impostare una password abilita la cifratura AES-256-GCM del file del database. La chiave è derivata dalla password e non viene mai memorizzata.

  • Con password: l'app la chiede all'avvio. Il database viene decifrato in memoria e ricifrato alla chiusura.
  • Senza password: il database è un normale file SQLite.
Dati: esporta, importa, ripristina
  • Esporta: scarica una copia JSON (solo dati principali) o un archivio completo .yfine (dati principali + plugin + impostazioni).
  • Esporta Excel / PDF: formati per stampa o condivisione.
  • Importa: scegli un file esportato. Una finestra di anteprima mostra cosa verrà importato prima di confermare.
  • Log: scarica o svuota il registro applicazione.
  • Ripristina tutti i dati: cancella ogni fonte, movimento, portafoglio, etichetta, ricorrente, risparmio, sfizio e notifica. Le impostazioni restano.
Scheda Importazioni

La scheda Importazioni è una procedura guidata passo-passo. Scegli la fonte di destinazione, seleziona un preset di formato (per esempio "CSV estratto conto"), carica il file, mappa le colonne se serve e rivedi la lista dei movimenti da creare. Il riconoscimento dei duplicati avviene nel passo di revisione.

Plugin

I plugin estendono Yfine con nuove pagine, voci di menu o logiche. Per installarne uno:

  1. Clicca il pulsante di caricamento e scegli l'archivio del plugin.
  2. Yfine esegue una scansione statica del codice. Le segnalazioni critiche bloccano l'installazione. Gli avvisi permettono di proseguire a tua discrezione.
  3. Dopo la scansione, conferma per installare.
  4. Riavvia l'app. La voce del plugin compare nella barra laterale.
Esporta i dati prima di qualsiasi "Ripristina tutti i dati" o installazione di plugin rischiosa. L'archivio .yfine contiene tutto il necessario per riportare l'app allo stato attuale.
I plugin girano con gli stessi permessi di Yfine. Lo scanner segnala i problemi evidenti, ma non può catturare tutto. Installa solo plugin da fonti che consideri affidabili.
