Settings

All of Yfine's preferences live here, split into tabs. The left sidebar is the tab navigator on desktop, and a scrollable row on mobile.

Tabs overview
Theme Light, dark, or system (follows your operating system). Also the mobile navigation style.
Language Interface language, date format, and base currency for totals.
Portfolios Turn live price fetching on or off.
Network Enable LAN access so other devices on your home network can open Yfine. Change the server port.
Security Set or change the password that encrypts your database.
Data Export your data, import a backup, download or clear logs, reset all data.
Imports Import movements from bank statements and other finance apps. Presets for common formats.
Plugins Upload custom plugins. A scan report flags anything that looks unsafe.
Theme

Three buttons at the top: Light, Dark, System. "System" follows the operating system setting and switches automatically when it changes.

Below: the mobile navigation style. Pick "Sidebar" to keep the left drawer on phones, or "Bottom" for a native-looking bottom bar.

Language
  • Language: English, Italian, Spanish, Ukrainian. Interface reloads in the new language on save.
  • Date format: dd/mm/yyyy, mm/dd/yyyy, or yyyy-mm-dd. Affects every displayed date across the app.
  • Base currency: the default used when creating a source or a saving without one selected.
Network

Yfine only listens on localhost by default. Turning on LAN access makes it reachable from other devices on your home network (useful for opening the app on a phone while your computer is running). Yfine shows the URL to type on the other device.

The server port can be changed if the default is already in use. A "restart required" note appears after you save.

Security

Setting a password enables AES-256-GCM encryption of the database file. The key is derived from your password and is never stored.

  • With a password: the app asks for it on startup. The database is decrypted in memory and re-encrypted on shutdown.
  • Without a password: the database is a normal SQLite file.
Data: export, import, reset
  • Export: download a JSON copy (core data only) or a full .yfine archive (core + plugins + settings).
  • Export Excel / PDF: formatted for printing or sharing.
  • Import: pick an exported file. A preview dialog shows what will be imported before you confirm.
  • Logs: download or clear the application log.
  • Reset all data: wipes every source, movement, portfolio, tag, recurring item, saving, whim, and notification. Does not touch settings.
Imports tab

The Imports tab is a step-by-step wizard. Pick the destination source, pick a format preset (for example, "Bank statement CSV"), upload the file, map columns if needed, and review the list of movements to be created. Duplicate detection runs during the review step.

Plugins

Plugins extend Yfine with new pages, menu items, or logic. To install one:

  1. Click the upload button and pick the plugin archive.
  2. Yfine runs a static code scan. Critical findings block the install. Warnings let you continue at your own discretion.
  3. After the scan, confirm to install.
  4. Restart the app. The plugin's menu item appears in the sidebar.
Export your data before any "Reset all data" or risky plugin installation. The .yfine archive holds everything needed to restore the app to the current state.
Plugins run with the same permissions as Yfine itself. The scanner flags obvious issues, but it cannot catch everything. Only install plugins from sources you trust.
